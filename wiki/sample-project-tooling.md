# Sample project tooling (gvt-construct3)

How the `gvt-construct3` plugin's MCP servers (construct3-chef and
c3-domain-manager) behave against the `sample/` Construct 3 project. All
findings were verified on 2026-10-21 with construct3-chef 2.1.0 and
c3-domain-manager 0.11.2, the versions pinned by gvt-construct3 3.4.0. Expect
this page to age with those pins.

## Project wiring

- The C3 project marker is `.gvt-agent.json` `paths.c3project`, which points at
  `sample/project.c3proj`.
- Chef's defaults follow from it: project id `sample`, root `sample/`,
  extractedDir `sample/extracted/`.
- The gvt-construct3 audit passes 15/15 required checks.
- `sample/` uses event sheets only: 2 event sheets, 2 layouts, 0 scripts.
- No `.c3addon` packages are bundled in `sample/`, so chef's addon validate and
  metadata-sync tools have nothing to check. The sample consumes the addon
  through Construct's installed addons or dev mode, not a bundled package.

## Known failures (benign)

- **`regenerate` fails with ENOENT.** `scriptsType` is `module`, but there is no
  `sample/scripts/` directory, so chef fails on `scripts/importsForEvents.ts`
  and none of its six generators run. Tracked as
  [construct3-chef#309](https://github.com/GenvidTechnologies/construct3-chef/issues/309).
  No workaround is needed for this repo; do not create a dummy scripts file just
  to satisfy chef.
- **`validate-project` permanently reports `[timelines] - transitions/`.**
  `project.c3proj`'s `timelines` section holds an empty, unnamed subfolder (C3's
  `transitions` folder) with no `timelines/transitions/` on disk. `sync-project`
  claims to update but writes identical bytes, so the drift never clears. It is
  benign: the file is editor-written and correct, so do not hand-edit it out.
  Tracked as
  [construct3-chef#310](https://github.com/GenvidTechnologies/construct3-chef/issues/310).

## Committed domain index

`sample/extracted/domain-index/` (`index.md`, `VideoPlayerSample.md`) is
generated by c3-domain-manager and is **committed on purpose** (decision
2026-10-21). It may show up as modified when the sample changes: regenerate it
and commit it alongside the sample change. `sample/domain-config.json`
configures it.

## After a plugin update

After a gvt-construct3 plugin update, the bundled MCP servers can fail to
connect (30 s CONNECT_TIMEOUT) while npx fetches the newly pinned versions.
Run `/mcp` to reconnect them.
